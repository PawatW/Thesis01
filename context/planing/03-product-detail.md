# Feature 03: Product Detail — หน้าสินค้า + เลือกแผนรอบส่ง

> เฟส: 2 | ฝั่ง: Buyer | สถานะ: ✅ เสร็จ (Phase 2) — ส่วนรีวิวเพิ่มใน Phase 4.5 | Workflows: [W03](../workflows/w03-browse-compare.md), [W04](../workflows/w04-subscribe-checkout.md)

## ทำอะไรได้

- รายละเอียดสินค้า: รูปหลายรูป (สไลด์), ชื่อ, คำอธิบาย, ขนาด/หน่วย, ร้าน (กดไปหน้าร้านได้)
- **ส่วนรีวิว:** คะแนนเฉลี่ย + การกระจายดาว + รายการรีวิวพร้อมป้าย "รับมาแล้ว N รอบ" ([17](17-reviews.md))
- **PlanPicker:** แผน subscribe ทุก cycle ที่ active เป็นการ์ดให้เลือก — ราคาต่อรอบ, จำนวนชิ้น/รอบ, ป้าย "ถูกกว่าซื้อครั้งเดียว X%"
- เลือกจำนวน (สูงสุด 10) → สรุปราคาอัปเดตสด → ปุ่ม "Subscribe" ติดล่างจอ

## หน้าจอ & Routes

| Route | หน้าจอ |
|---|---|
| `(buyer)/product/[id].tsx` | หน้าสินค้า |
| `shop/[id].tsx` | หน้าร้าน (สาธารณะ) — โลโก้ + สินค้าของร้าน (reuse `ProductCard`) |

## Components หลัก

- `ImageCarousel` — สไลด์รูป + จุดบอกตำแหน่ง
- `PlanPicker` — radio cards; แต่ละใบ: ป้าย cycle (ทุก 2 สัปดาห์/เดือน/2 เดือน), ราคา, ชิ้น/รอบ, % ส่วนลด; ค่าเริ่มต้น = แผนที่ % ส่วนลดสูงสุด
- `QtyStepper`, `PriceSummaryBar` — แถบล่างติดจอ: "฿255 / เดือน" + ปุ่ม Subscribe
- `DiscountBadge` — สูตรกลางอยู่ `src/features/catalog/pricing.ts` (ใช้ร่วมกับ 02/04/11)

## Data & Queries (API)

| Endpoint | ใช้ที่ |
|---|---|
| `GET /catalog/products/:id` | ทั้งหน้า — สินค้า + ร้าน + แผนทุกรอบ + **รีวิว** (ชื่อผู้รีวิวถูก mask แล้วที่ service) มาในคำขอเดียว |

- สินค้าที่ถูกระงับหรือปิดขายตอบ **404 เหมือนไม่มีอยู่** (ผ่าน `VISIBLE_PRODUCT` เดียวกับหน้า catalog)
- response ของรีวิว **ไม่มี `buyerId` / `subscriptionId`** เด็ดขาด — รีวิวต้องไม่กลายเป็นช่องทางสืบว่าใครซื้ออะไร ([security-design §4](../../docs/security-design.md))
- แผนที่ปิดรับสมาชิกใหม่ถูกกรองทิ้งฝั่งแอป และถ้าเหลือ 0 แผน ปุ่มเปลี่ยนเป็น "ปิดรับสมาชิกชั่วคราว" — **ด่านจริงอยู่ที่ checkout** ซึ่งตอบ 409 ถ้าแผนเพิ่งถูกปิด
- กด Subscribe → `router.push('/checkout/' + planId)`

## Validation & Edge cases

- product id ไม่มีจริง / is_active = false → หน้า "ไม่พบสินค้า" + ปุ่มกลับ catalog
- ราคาแผนแพงกว่าซื้อครั้งเดียว (ส่วนลดติดลบ) → ไม่แสดงป้ายส่วนลด (ไม่โชว์ค่าติดลบ)
- ยังไม่ล็อกอินแล้วกด Subscribe → เด้งไป login แล้ว **กลับมาหน้าเดิมพร้อมแผนที่เลือกไว้** (เก็บ redirect param)
- คำอธิบายยาว → ตัด 4 บรรทัด + "อ่านเพิ่มเติม"

## Acceptance Criteria

- [ ] เห็นทุกแผน active ของสินค้า เลือกแล้วราคาสรุปอัปเดตทันทีตามจำนวน
- [ ] % ส่วนลดตรงกับสูตรกลาง และไม่แสดงเมื่อติดลบ
- [ ] สินค้าที่ไม่มีแผน active กด Subscribe ไม่ได้
- [ ] กด Subscribe โดยยังไม่ล็อกอิน → login → กลับมาที่เดิม
- [ ] กดชื่อร้าน → หน้าร้านแสดงสินค้าอื่นของร้าน
