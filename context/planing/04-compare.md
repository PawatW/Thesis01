# Feature 04: Compare — เปรียบเทียบสินค้าข้ามร้าน

> เฟส: 2 (ทำจริง 2026-08-19) | ฝั่ง: Buyer | สถานะ: **เสร็จแล้ว** | Workflows: [W03](../workflows/w03-browse-compare.md)
> มาจาก objective ใน proposal: "compare and manage subscriptions from multiple brands"

## ทำอะไรได้

- เลือกสินค้า **หมวดเดียวกัน 2-4 ชิ้น** เข้าถาดเทียบจากหน้าหมวด แล้วดูตารางเทียบ:
  ราคาต่อรอบทุก cycle · **ราคาต่อหน่วย** (เทียบข้ามขนาดได้จริง) · % ส่วนลด · รอบส่งที่มี · จำนวน subscriber · **คะแนนรีวิว + จำนวนรีวิว** ([17](17-reviews.md) — เทียบคุณภาพ ไม่ใช่แค่ราคา)
- Subscribe ตรงจากคอลัมน์ในตารางได้

## หน้าจอ & Routes

| Route | หน้าจอ |
|---|---|
| `app/compare.tsx` | ตารางเทียบ — คอลัมน์ = สินค้า, แถว = มิติเทียบ · scroll แนวนอนพร้อมคอลัมน์ชื่อแถวกว้างคงที่ · วางนอกกลุ่ม `(buyer)` เหมือน `product/[id]` เพราะเป็นหน้าที่ push ทับ ไม่ใช่แท็บ |

## Components หลัก

- `CompareProvider` (React Context) — `items[]`, `categoryId`, actions: toggle/restartWith/remove/clear · **client state ล้วน ไม่แตะ DB** · ใช้ Context แทน zustand ตามที่ร่างไว้ เพราะ state มีแค่ 2 ตัวและไม่มีใครนอกฟีเจอร์นี้ใช้ — ไม่คุ้มกับการเพิ่ม dependency (CLAUDE.md ข้อ 6)
- `CompareTrayBar` — แถบลอยล่างหน้าหมวด: "เทียบ (3) · ดูตาราง · ล้าง"
- `CompareTable` — แถวเทียบ: รูป+ชื่อ+ร้าน / ราคา 2w / ราคา 1m / ราคา 2m / **฿ ต่อ {unit}** / ส่วนลดสูงสุด / subscriber / ปุ่ม Subscribe ต่อคอลัมน์
- ไฮไลต์ค่าที่ดีสุดของแต่ละแถว (เช่น ราคาต่อหน่วยต่ำสุด) ด้วยพื้นหลังอ่อน

## Data & Queries

- ไม่ query เพิ่ม — ใช้ข้อมูลที่โหลดมาแล้วจากหน้าหมวด (products + plans + product_stats)
- ราคาต่อหน่วย = `price_per_cycle ÷ qty_per_cycle ÷ net_amount` → แสดง "฿0.85 / g" — สูตรอยู่ `pricing.ts` เดียวกับ feature 03
- cycle ที่สินค้านั้นไม่มีแผน → เซลล์ "—"

## Validation & Edge cases

- กดเทียบสินค้าต่างหมวด → toast "เทียบได้เฉพาะหมวดเดียวกัน" + ปุ่ม "ล้างถาดแล้วเริ่มใหม่ด้วยชิ้นนี้"
- ครบ 4 แล้วกดเพิ่ม → toast "เทียบได้สูงสุด 4 ชิ้น"
- เหลือชิ้นเดียวในถาด → ปุ่มดูตาราง disabled (เทียบ 1 ชิ้นไม่มีความหมาย)
- `net_amount/unit` ไม่มี → แถวราคาต่อหน่วยแสดง "—" และไม่ร่วมไฮไลต์
- หน่วยต่างกัน (g vs ml) → เทียบต่อหน่วยเฉพาะชิ้นที่หน่วยตรงกัน ชิ้นอื่น "—" + เชิงอรรถ
- ออกจากหน้าหมวด → ถาดคงอยู่ (global store) แต่ล้างเมื่อเปลี่ยนหมวด

## Acceptance Criteria

- [x] เพิ่ม/ถอดสินค้าจากถาด แถบลอยอัปเดตจำนวนถูกต้อง (**TC-080**)
- [x] ตารางแสดงครบทุกมิติ ค่าดีสุดถูกไฮไลต์ · ราคาต่อรอบตรงกับแผนใน DB (TC-080 เทียบกับ `product_plans` ตรง ๆ)
- [x] กันข้ามหมวด (พร้อมปุ่ม "ล้างถาดแล้วเริ่มใหม่") / เกิน 4 ชิ้น พร้อมข้อความ (**TC-081**)
- [x] ต่ำกว่า 2 ชิ้น → ปุ่มดูตารางกดไม่ได้ + บอกว่าต้องเลือกอีกกี่ชิ้น
- [x] scroll แนวนอนได้ทั้ง web และมือถือ · คอลัมน์ชื่อแถวกว้างคงที่
- [x] Subscribe จากตาราง → เข้า checkout ด้วยแผนที่คุ้มที่สุดของสินค้าชิ้นนั้น
- [x] สินค้าที่ยังไม่มีรีวิวแสดง "ยังไม่มีรีวิว" และไม่ร่วมไฮไลต์ · หน่วยไม่ตรงกันแสดง "—"

## ข้อมูลที่เกี่ยวข้อง

ไม่มีตารางใหม่ — ใช้ `products`, `product_plans`, view `product_stats`

## Out of scope

- เทียบข้ามหมวด, บันทึกรายการเทียบ, AI แนะนำ
